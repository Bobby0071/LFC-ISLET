# LFC-ISLET 1.0.0

基于 fly-island v3.2.5 的首个独立发行版。升级前请注意：如果你装过上游 fly-island，请先卸载它，否则两个程序会同时运行、窗口互相重叠。

## 更新内容

- **新增系统页**：直接读取 CPU、内存与网络速率，不需要额外监控软件
- **新增全应用通知**：「通知」页签收录所有应用的提示，不再只限 QQ；其他应用的通知只累加角标，不会弹出打断操作
- **新增系统音量**：音乐页可调 Windows 输出音量，与播放进度分开，无播放时也能用
- **游戏模式手动开关**：打开后不论是否全屏都只响应点击，窗口化游戏同样适用
- **浅色主题重做**：改用 macOS 色值，深色模式自动跟随
- **关于页精简**：只保留 GPL-3.0 归属声明
- **修复贴边展开的画面抖动**与收起条遮挡面板顶部的问题
- **应用标识改为 com.lfcislet.island**，旧数据自动迁移；已断开上游更新通道

---

## What's new

- **System page**: CPU, memory and network rates without extra monitor software
- **Notifications from every app**: the Notifications tab collects them all, not just QQ; another app's toast only bumps a badge
- **System volume**: set the Windows output level from the music page, with any player and even when nothing is playing
- **Game mode switch**: hovering does nothing and a click opens the island, windowed games included
- **Light theme reworked** with macOS colour values; dark mode follows
- **About trimmed** to the GPL-3.0 attribution only
- **Fixes**: jitter when expanding from the top edge, and the collapsed bar covering the panel top
- **App id is now com.lfcislet.island** with data migration, and the upstream update channel is disconnected
